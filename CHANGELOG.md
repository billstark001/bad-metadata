## [0.1.0] - 2026-11-27

### Added

- Shared metadata scanning and cleaning engine for Windows and macOS.
- AppleDouble header detection, `.DS_Store`, Spotlight, and FSEvents cleanup; optional Trash cleanup.
- English CLI and English/Simplified Chinese native MyGo GUI with equivalent cleaning operations.
- Preview, reversible quarantine, explicit permanent deletion, cancellation, and conflict-safe restore.
- JSON reports, portable builds, macOS application bundles, Make targets, and Windows/macOS CI.
- Live CLI progress on stderr and native desktop progress with visited counts, operation totals, and content-verification bytes.
- Shared application icon, multi-resolution Windows executable icons, macOS bundle icons, and reproducible platform resource generation.
